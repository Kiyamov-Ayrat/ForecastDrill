# БурПрогноз — прототип интерфейса системы прогноза осложнений при бурении

Мокап разбит на модули: каждый интерфейс (экран) имеет собственный HTML-рендер (JS),
собственные стили (CSS) и регистрируется в общем реестре экранов.

## Структура проекта

```
index.html               — каркас страницы (шапка, #app, подключение всех css/js)
css/
  base.css               — CSS-переменные тем (светлая/тёмная), сброс, типографика
  layout.css             — общая раскладка: шапка, сайдбар, сетки, toast, адаптивность
  components.css         — переиспользуемые компоненты: карточки, кнопки, таблицы, бейджи
  screens/               — стили конкретного интерфейса
    login.css   S-1  Вход в систему
    risk.css    S-2  Риск по скважине
    dash.css    S-3  Состояние скважин
    well.css    S-4  Скважина: риск и предупреждения
    journal.css S-5  Журнал и разбор инцидента
    rep.css     S-6  Отчёты
    quality.css S-7  Качество данных
    src.css     S-8  Источники данных и паспорт скважины
    thr.css     S-9  Пороги тревог
    models.css  S-10 Модели: метрики и переобучение
    users.css   S-11 Пользователи и роли
js/
  main.js                — точка входа: переключатель темы, первый render()
  core/
    utils.js             — $, lvl/LT, B (бейджи), T (таблицы), toast
    state.js             — глобальное состояние st, справочники META (экраны) и ROLES (роли)
    data.js              — демонстрационные данные: ряды телеметрии, список скважин, WB()
    charts.js            — SVG-графики: spark() (тренды с порогами), pcard() (индикаторы)
    router.js            — реестр SCREENS, registerScreen(), go(), render(), login/logout
  screens/               — по одному файлу на интерфейс (HTML + логика экрана)
    login.js risk.js dash.js well.js journal.js rep.js
    quality.js src.js thr.js models.js users.js
```

## Как добавить новый интерфейс

1. Создать `js/screens/<name>.js` со строкой `registerScreen('<name>', () => '...html...');`
2. Добавить описание экрана в `META` и пункт навигации в нужные роли (`js/core/state.js`).
3. Создать `css/screens/<name>.css` для его стилей.
4. Подключить оба файла тегами `<script>` / `<link>` в `index.html`.

## Запуск

Открыть `index.html` в браузере (для строгих настроек CORS — через любой статический сервер,
например: `python3 -m http.server 8000`, затем http://localhost:8000).

Демо-вход: логин/пароль любые непустые; роль выбирается в списке. Данные демонстрационные.
